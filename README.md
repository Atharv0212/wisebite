# Wise-Bite
This project is aimed on a public-awareness on food items system. It gives honest opinions on packaged food article by scanning it's barcode, incredient table, item ID or the food's image itself.
## Why?
Every packaged food article can have hidden incredients, whether not mentioned, or hidden behind some complex incredient name. This website helps you identify elements, create detailed report on food, compare similar items, suggest better alternatives based on all the incredients present. The website also includes personlization which further improves the reports on food articles helping you further improve dietery experience.
## Dataset and API
The tool uses dataset from Open-Fast-food API and News API. It also used gemini-flash API to present data in resonable and understandable format including an intelligent mind behind all the complex data.
